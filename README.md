# NTUST ECE Badminton 問題回報區

這裡專門用來回報 [NTUST ECE Badminton](https://ntust-ece-badminton-v1.pages.dev/) 的網站問題與功能建議。

> 此儲存庫不含正式網站原始碼、球員資料或部署設定，公開回報不會影響正式網站。

## 開發進度

所有新回報會自動加入 [NTUST ECE Badminton 開發看板](https://github.com/users/s59909414-alt/projects/1)，並依序經過：

**待處理 → 進行中 → 待驗收 → 完成**

看板另有「全部項目」清單，可一次查看負責人與目前狀態。

## 如何回報

1. 進入 [Issues](https://github.com/s59909414-alt/NTUST-ECE-Badminton-Issues/issues)。
2. 按 **New issue**。
3. 選擇「錯誤回報」或「功能建議」。
4. 按表單提供重現方式、手機型號與瀏覽器等資訊。

## 請勿公開張貼

- 管理員密碼、活動密碼或任何金鑰
- 完整電話、學號、地址或其他個人資料
- 未遮蔽個人資訊的螢幕截圖

如需附圖，請先遮蔽姓名、電話、學號及密碼。
